# Foundations and display contracts

Owner: Evenkit. Maturity: pilot. Example consumer: the local component catalog. This module implements inventory A01–A07, A11, H01–H04 and H08.

These original kit components use the existing Apple Minimal values and [Card contract](/Users/nationalbank/GitHub/ai-config/claude/uiux-contract/components/card.yaml). They add no runtime dependency, asset or visual token. Components receive ordinary React/native attributes and forwarded refs. The host owns record data, routing, action behavior and focus recovery after removing content.

| A01 | `Prose` scopes native headings, paragraphs, links, lists, quotes and code. Sections receive more space before their heading than after it; nested quote paragraphs have clean edges and code blocks contain their scrolling. `Heading` selects semantic level independently of visual size. `.pk-text-muted` and `.pk-caption` are optional text recipes. Grid accepts a maximum of one to four columns, reduces the count when its container cannot fit the existing 260px sidebar-width token per column, and retains the viewport caps at existing breakpoints. A single column fits containers narrower than 260px; unused tracks remain when there are fewer children than columns. |
| A04 | `Separator` is decorative by default. Set `decorative={false}` for a structural separator; vertical orientation supplies the correct ARIA orientation. |
| A05 | `Card`, `CardHeader`, `CardBody`, `CardFooter` and `CardMedia` group related content. Variants are default, elevated, outline and ghost. The passive card has no hover or click semantics. | A07 | `ActionGroup` is a named native-tab-order group, suitable for related actions. It intentionally does not claim `role="toolbar"`; use this recipe when each action belongs in normal Tab order. Full roving toolbar behavior is outside this simple group API. |
| A11 | `VisuallyHidden` retains text in the accessibility tree. `SkipLink` moves to an existing focusable target; give the target `tabIndex={-1}`. Its focus surface fits the viewport, wraps long labels and keeps a 44px minimum target. Focus reveal uses the fast motion token; reduced motion removes the transition. `LiveStatus` remains mounted while its text changes, with polite atomic status announcements by default. |
| H01 | `Avatar` exposes the person's name once, shows initials until its image loads, falls back after failure and retries when src changes. Image content is decorative inside the named root and fades in after loading; reduced motion removes the transition. Sizes are 32, 40 and 48px including the border. `AvatarGroup` overlaps members with a surface ring and a distinct named overflow count. Logical trailing margins and matching group padding keep wrapped rows within the container in either direction. |
| H02 | `Tag` is passive by default. An `onSelectedChange` callback creates a pressed-state button with a reserved decorative checkmark slot, so its label stays in place when selected. The selected border and checkmark reinforce the state. Selected neutral tags use the theme accent and tinted fill; semantic tones retain their colours. Hovering the selected label preserves its colour. `onRemove` adds a separately named sibling button behind a logical divider; select/remove controls never nest, and both retain visible focus. `TagGroup` groups related tags; the host restores focus when removing one. | H03 | `DataList` and `DataListItem` keep native dl/dt/dd semantics. Rows use 16px vertical spacing, muted terms and medium-weight values, with 24px between desktop columns. | H04 | `ListItem` is a div composition for media, title, description, metadata and trailing actions. Its grid omits empty media/action columns. At a container width of 639px or less, content and actions span the available columns and actions align beneath the text; a viewport fallback keeps the same arrangement on narrow screens. Titles are semibold, descriptions use body-small and metadata forms a wrapping group. Put it inside native li elements when presenting a list. Headings and links stay host-controlled. |
| H08 | `Kbd` uses native kbd markup and the mono font. A 24px minimum size centers short glyphs, while longer key names expand naturally. The lower border and small shadow distinguish keys from surrounding text. Supply platform-specific characters and an accessible label when a shortcut symbol needs explanation. |

Library CSS is scoped to `pk-` classes. All values derive from existing tokens; structural zero, percentages and grid fractions are layout values. Controls keep visible focus and at least 44px targets on narrow/coarse-pointer screens. Long text wraps, logical properties support RTL, and content remains readable in all eight light/dark themes. Short image and selection transitions use the fast motion token and honor reduced motion.

## Usage and composition

Import token CSS before UI CSS. The catalog has a separate searchable entry and complete usage snippet for each inventory item. The page/layout recipes do not impose a global reset or application landmark structure.

Use one useful boundary around a related unit. Repeated list rows and descriptions can use rules without a surrounding card. The default Card follows the existing contract's small shadow; ghost removes the boundary and shadow.

For tag removal, move focus to another surviving control before the selected tag is removed. Keep a persistent `LiveStatus` for the result. The catalog example restores focus to its Reset tags control. For skip navigation, keep the destination in the document and focusable with `tabIndex={-1}`.
