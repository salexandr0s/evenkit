# Actual component motion pass: 2 November 2026

This pass improves the reusable library in `packages/ui/src`. All 116 catalog entries have an individual underlying-source review. Catalog task prompts and framing receive no improvement credit in this pass.

## Library changes

| Component | Result |
|---|---|
| Button | The label and spinner crossfade within the existing footprint. Pending buttons retain their action contrast while remaining disabled. Hidden spinner work stops; rapid loading changes retarget the transition. |
| Combobox and Autocomplete | The popup enters and exits with reversible opacity and anchored translation. Base UI retains its real surface through exit; its Radix dismissal registration ends at logical close. Inert closed content rejects queued activation. |
| Accordion and Collapsible | Measured height, spacing and content opacity move neighboring content continuously. Reversal starts from the current pose. Initial-open and server-rendered content retain natural geometry; custom IDs, slotted content, refs, caller styles/ARIA and forceMount behavior are preserved. |
| Progress and Meter | Native determinate fills move between values and retarget when a new value arrives. Labels and native value semantics update immediately. |
| Segmented and toggle controls | Foreground and border feedback move with the existing selected surface instead of changing abruptly. |
| ChatPanel and ChatWidget | Conversation history opens a track continuously instead of shifting the conversation 260 pixels in one frame. Hidden controls stay hidden; drafts, focus and streaming state are retained. |
| Image and Thumbnail | Successful content reveals over the base motion interval without resizing its frame. Error actions retain their visibility and focus. Cached and fast arrivals may also reveal over the same interval. |

Existing tokens define the timing: 120 ms feedback, 160 ms control/disclosure motion and 220 ms larger chat geometry. Reduced motion reaches the final state immediately. Content is translated or revealed without scaling its text. The [Stageshow motion reference](../.agents/skills/stageshow/references/motion.md) supplies the cause, continuity and payoff principles. The [Base UI animation contract](https://base-ui.com/react/handbook/animation) supplies popup transition states and mount ownership.
