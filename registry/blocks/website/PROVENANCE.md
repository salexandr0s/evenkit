# Website block provenance

Created for Evenkit on 25 October 2026 from local base commit `b588b1b` on `codex/component-improvements`. Work is isolated on `codex/website-blocks`.

The React compositions, form state handling, CSS, examples and specimen SVG are original code and content written for this repository. No external website template, customer content, testimonial, logo, photograph or performance claim was copied. Paper Observatory, its services and its newsletter are fictional examples. The sample email uses the reserved `.invalid` domain.

The specimen image is an original inline SVG drawing in `examples.tsx`, encoded as a data URL for portable demos. The design pass replaced the simple outline with an imagined fern study and a cropped detail of the same vector artwork. Its fixed neutral ink/paper colors belong to the illustration; UI surfaces, typography and controls use kit tokens. The studio mark reuses Evenkit's Leaf icon. Replace these demo assets when adopting the blocks. Hosts with a restrictive image CSP may need a local file instead of the demo data URL.

The blocks reuse installed `@evenkit/ui` and `@evenkit/tokens` components and styles. Navbar, Accordion, fields, Image, layout, prose, icons and feedback retain the existing package implementations and their notices. Dependency attribution is maintained in the package provenance and license files. No new runtime dependency or license grant is introduced here.

Application handlers, real content, asset permissions, routes, locale choices, consent wording and legal policies are supplied by the consuming application. The examples do not implement those policies.
